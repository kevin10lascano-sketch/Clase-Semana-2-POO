# Semana 2 - Programación Orientada a Objetos en Python

Este repositorio contiene ejemplos básicos de Programación Orientada a Objetos desarrollados en Python.

El objetivo es reforzar los conceptos estudiados durante la Semana 2 de la asignatura Programación Orientada a Objetos.

## Contenidos

- Clase y objeto
- Abstracción
- Encapsulación
- Herencia
- Polimorfismo

Cada archivo presenta un ejemplo sencillo y comentado para facilitar la comprensión del estudiante.

## Requisitos

Para ejecutar los ejemplos se necesita tener instalado:

- Python 3.x
- Visual Studio Code, PyCharm u otro editor de código

## Archivos del repositorio

| Archivo | Tema |
|---|---|
| `01_clase_objeto.py` | Relación entre clase y objeto |
| `02_abstraccion.py` | Abstracción |
| `03_encapsulacion.py` | Encapsulación |
| `04_herencia.py` | Herencia |
| `05_polimorfismo.py` | Polimorfismo |

## Cómo ejecutar los ejemplos

Abrir una terminal dentro de la carpeta del proyecto y ejecutar:

```bash
python 01_clase_objeto.py
